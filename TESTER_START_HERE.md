# MemoryPal Tester Guide - Start Here

Thanks for testing MemoryPal. This beta is version 0.43.0 (development milestone v67). It takes about 20-30 minutes to try the main parts.

## 1. Install

**Option A - installer (recommended)**

1. Double-click `MemoryPalSetup.exe`.
2. If Windows SmartScreen says "Windows protected your PC", click **More info**, then **Run anyway**. The beta is not code-signed yet, so this warning is expected.
3. Keep the default install folder. You do not need administrator access.
4. Leave "Launch MemoryPal" ticked and click **Finish**.

**Option B - no install (portable)**

1. Unzip the package somewhere you can find it, such as your Desktop.
2. Open the `MemoryPal` folder and double-click `MemoryPal.exe`.
3. Keep the whole folder together. The EXE will not run if it is copied out on its own.

## 2. First launch

MemoryPal opens with a **Welcome** screen. Choose the option that fits you best:

- **I'm studying** - school, exams, languages
- **Help with everyday memory** - names, routines, larger text, calmer pace
- **I'm helping someone else** - setting it up for a family member
- **Just exploring**

Then choose a text size, decide whether questions should be read aloud, and pick **Start the Tour** or **Skip the Tour**. You can change all of this later in **Settings > Welcome & tour**.

## 3. What to try

Use `TESTING_CHECKLIST.md` if you want the full list. The short version:

1. Take the guided tour.
2. **Capture** - paste a few notes or type 3-5 question/answer cards.
3. **Review / Test Lab** - answer a card, press Smart Check, then rate it.
4. **Read aloud** - press a Read aloud button on a card.
5. **Study Plan** - build a plan for today, then a plan over several days.
6. **Associations** - paste 12 or more items and try Peg list and Memory palace.
7. **Puzzles** - play one or two games.
8. **Settings** - try Large text, Higher contrast, and More time.

## 4. Send feedback

- In the app, open **Feedback Log**, add notes as you go, then use **Export CSV** and send me the file.
- For crashes or odd behaviour, a screenshot and one sentence about what you clicked is very helpful.
- Please also mention your Windows version and screen scaling (for example 100%, 125%, or 150%).

## 5. Your data

- Cards and settings are saved only on your computer, in `%LOCALAPPDATA%\MemoryPal`. Nothing is uploaded.
- Uninstalling MemoryPal (Windows Settings > Apps) keeps your data. Delete that folder only if you want a fresh start.
- Installing a newer tester build over this one keeps your cards.

## Known limits in this beta

- Read aloud uses the voice built into Windows. It needs no internet connection, but some cut-down Windows installs have no voice.
- Audio/video recording and speech-to-text are not included in the tester build.
- The Mac version is a separate download.
